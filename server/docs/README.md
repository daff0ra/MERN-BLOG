# Dokumen Produk

Dokumen ini menjadi baseline produk untuk pengembangan aplikasi blog menjadi portofolio naratif profesional.

| Dokumen | Isi |
|---|---|
| [PCD — Product Concept Document](./product-concept.md) | Masalah, visi, pengguna, proposisi nilai, ruang lingkup, dan indikator keberhasilan |
| [Kebutuhan, user story, dan acceptance criteria](./requirements.md) | Kebutuhan pengguna, kebutuhan fungsional/nonfungsional, story, dan kriteria penerimaan |
| [DFO — Data Flow Overview](./data-flow-overview.md) | Aliran data, batas kepercayaan, model domain, dan kontrol privasi |
| [Persiapan delivery](./delivery-readiness.md) | Tahapan MVP, keputusan produk, risiko, operasional, dan Definition of Done |
| [Catatan refaktor dan pengembangan server](./refactor-notes.md) | Struktur yang sudah dibuat, endpoint, keputusan desain, test, dan batas implementasi |

**Status:** dokumen produk adalah rancangan target untuk validasi. Implementasi saat ini mencakup autentikasi, profil dasar, draft karya, preview, dan publikasi karya individual. Belum semua kebutuhan MVP tersedia.

Panduan belajar pemrograman tersedia secara lokal di `learning-guide.md`. File tersebut sengaja dikecualikan dari Git dan tidak ikut dibagikan melalui repository.

## Istilah

- **PCD:** Product Concept Document, dokumen konsep dan arah produk.
- **DFO:** Data Flow Overview, gambaran aliran data sistem.
- **Portofolio naratif:** kumpulan tulisan terkurasi yang menunjukkan cara berpikir, pengalaman, kemampuan, dan pemahaman pemiliknya.
- **Pembaca/reviewer:** pihak yang menerima tautan portofolio untuk menilai karya kandidat.
